# Writer — CLI для написания книг через AI

Автономный CLI-инструмент. Читает конфиг, декомпозирует тему на главы, пишет каждую главу, сохраняет результат в .md.

## Использование

```bash
# Собрать
go build -o writer.exe ./cmd/writer/

# Запустить
writer -config ./book.json
```

## Конфиг (book.json)

```json
{
  "provider": {
    "model": "gpt-oss:20b",
    "endpoint": "http://localhost:1234/v1/",
    "key": "lmstudio",
    "context_size": 62000,
    "timeout": "4h",
    "thinking_mode": false,
    "reasoning_effort": "high"
  },
  "modes": [
    {
      "name": "ref",
      "label": "Мои источники",
      "prompt_file": "D:\\go\\creative\\prompts\\universal.promt",
      "books_folder": ["D:\\books\\history"]
    }
  ],
  "writer": {
    "query": "Напиши книгу об истории Древнего Рима.",
    "output": "./books/древний-рим.md"
  }
}
```

- `provider` — настройки AI (модель, endpoint, ключ)
- `modes` — список книжных папок для поиска фактов (через BookTools)
- `writer.query` — тема книги
- `writer.output` — путь к итоговому .md файлу

## Процесс

1. **Декомпозиция** — AI-редактор разбивает тему на 5-7 глав, для каждой указывает название и вопросы
2. **Написание** — AI-писатель пишет каждую главу последовательно (использует BookTools для поиска фактов)
3. **Компиляция** — все главы собираются в один .md файл

Во время работы AI использует механизм "Продолжить / Я закончил":
- Если ответ не умещается в одно сообщение — сервер автоматически отправляет "Продолжить"
- Когда AI пишет "Я закончил" — глава считается завершённой
